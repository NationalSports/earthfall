# Lightweight assets for Frontline

| Repository | Best use in Earthfall | License and integration |
| --- | --- | --- |
| [KayKit City Builder Bits](https://github.com/KayKit-Game-Assets/KayKit-City-Builder-Bits-1.0) | Background city blocks where the player sees the roof and silhouette. Keep the detailed theater and scanned storefronts at street level. | CC0. The free pack has 32+ low-poly models, glTF exports and a shared texture atlas. Batch repeated meshes by material. |
| [KayKit Space Base Bits](https://github.com/KayKit-Game-Assets/KayKit-Space-Base-Bits-1.0) | Modular outbuildings and mining colony silhouettes on Ceres. Choose a small matching subset and tint it to the station palette. | CC0. Use the free pack and keep its license alongside imported models. |
| [pmndrs/ecctrl](https://github.com/pmndrs/ecctrl) | Reference for testing third-person movement on sloped and moving surfaces. Compare its controller demo to the same maneuvers in Frontline. | MIT. The controller uses React Three Fiber and Rapier. Frontline uses Three.js directly, so evaluate individual behaviors before considering a controller migration. |

These are candidates for subsequent art and gameplay work. This build uses Earthfall's own bridge illustration, soldier model and bus, plus an original theater mesh.
