# Combat pass captures

Actual runtime screenshots at 1280 × 800, captured by `test/browser.cjs` in headless Chrome with software rendering. HUD hidden for review. These are procedural runtime models, not generated concept art.

- [Vehicle interior](vehicle-interior.png): dusk; open door, seats, dashboard and missing glass on a wreck.
- [Blast after three seconds](blast-after-3-seconds.png): storm; the immediate flash has ended, with ground flame, a rising smoke column and debris still active.
- [Soldier materials](soldier-materials.png): dusk; muted teal, worn brass, exposed undersuit and restrained cyan.

The supplied soldier image guided materials and lighting; the procedural geometry does not reproduce its photorealistic detail.
